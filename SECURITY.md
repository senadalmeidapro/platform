# Security Policy

## Supported versions

This repository is under active development. Security fixes are applied to the current development branch; no older release line is currently promised support.

## Reporting a vulnerability

Report suspected vulnerabilities privately through GitHub's **Report a vulnerability** flow on this repository when it is enabled. If private reporting is unavailable, contact the repository maintainers through a private channel provided by the hosting organization.

Do not publish exploit details, credentials, personal data, production records, or unredacted logs in a public issue. Include the affected version or commit, impact, reproduction steps, and any safe proof of concept. The maintainers will review reports and coordinate a fix and disclosure with the reporter.
